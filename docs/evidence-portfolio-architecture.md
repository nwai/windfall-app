# ADR: Frozen Evidence Portfolio EP-1

Status: Accepted for experimental use
Date: 2026-10-07

## Context

Windfall has a family registry and a panel ownership manifest. Several panels transform the same counts or consume the same neighbour/drought observations. Treating every panel as another vote would exaggerate agreement. The journal must preserve the recipe that existed before the outcome, including unsuccessful alternatives and controls.

## Decision

EP-1 reconstructs frequency, drought, previous-neighbour and gated monthly-stage inputs directly from strict recorded history. Related count-derived views are omitted as additional votes. Strict and empirical drought share a maximum contribution. Each group contributes at most one point per number. Declared groups organise evidence; statistical independence is not assumed.

Four fixed recipes select distinct main rows from a seed-defined uniform proposal pool: equal bounded support, support breadth, gated stage context, and coverage novelty. The DGA supplementary-role method is reused and disclosed. Four unplayed uniform controls and one alternative portfolio per active omitted group are built from the same proposals. All are frozen together.

Active forced inclusions/exclusions apply to all rows. Other generator settings are recorded as context and explicitly not applied. The portfolio has its own versioned policy rather than inheriting arbitrary generator weighting.

Construction runs in a worker. Review/save is explicit. One journal entry contains four forecasts and the full snapshot; no purchase is inferred. Exact-date scoring uses only subsequently recorded valid real results. A changed prior-history fingerprint invalidates attribution. Journal backups preserve snapshots. Pending edits may change notes/review, but retain the frozen rows.

Formal audit takes the earliest reviewed, unarchived snapshot per target. Freeze/save/review must precede the target calendar date in Australia/Melbourne. The initial verdict requires 30 distinct targets across six months. Approximate month-level intervals are descriptive and do not promote a model or change weights. The journal is an outcome registry, not the primary training source.

## Alternatives Considered

Combining rendered panel outputs would depend on panels being opened and could duplicate upstream evidence. Feeding everything through the main generator would couple this fixed experiment to a changing collection of controls. Automatically adapting weights after each outcome would invite small-sample fitting. These alternatives are deferred.

## Consequences

The result is reproducible, inspectable and capable of accumulating measured future outcomes. It does not establish predictive lift. Families without a validated adapter remain visible in the availability ledger; they require a separately versioned, predeclared adapter and tests before participation. Same-day predictions retain descriptive value but cannot support the initial formal audit.

## Supplementary Policy Replay SPRA-1

Selection Insights includes a separate observe-only comparison of Current Auto supps, pair-blend evidence, and all-history co-draw ordering. A shared production construction function supplies EP-1's four exact eight-number sets without manufacturing a saved preset or historical freeze timestamp. Every policy receives the same sets; only role assignment changes. A known-eight benchmark is reported separately from production EP selections.

The fixed protocol uses 60 prior draws, a chronological 70/30 development/confirmation split, a newest-N prior window frozen at run start, a fixed proposal seed, and no current user hard constraints. Target roles are revealed only for scoring. Exact enumeration of all 28 assignments supplies random-role expectations against real outcomes; it creates no synthetic history. Skipped production targets and numerical/no-evidence fallbacks remain in the ledger and JSON export.

Development chooses one policy using portfolio mean supplementary-role hits and fixed ties. Confirmation cannot choose a new winner. The conservative descriptive screen requires 60 later portfolio targets across six months, positive month-level difference ranges against current and exact-random references in both benchmarks, preserved exact-pair results and main/prize metrics, and no extra duplicate playable main rows. Ranges use 2.58 standard errors, not a calibrated probability or proof of independence.

Because the loaded CSV has already been inspected during development, the later block is retrospective historical confirmation, not an untouched prospective holdout. Rerunning different windows or seeds after seeing outcomes is exploratory. Even a positive result is only a candidate for a future pre-draw shadow test. This audit never promotes a method, changes EP-1 construction, writes a journal entry, or creates an additional evidence-family vote.

## EP-R1 Shadow Challenger and EP-AUDIT-1

EP-1 rows, controls and saved snapshots remain unchanged. New snapshots optionally
contain an EP-R1 challenger, frozen at the same cutoff using the same proposal
pool, number constraints and evidence. Existing imports without that field remain
valid; a missing historical challenger is never reconstructed after its outcome.
Damaged challenger imports are rejected instead of repaired with invented values.

EP-R1 gives tied frequency counts equal midrank support and includes all ties at
the top-12 boundary. Non-stage support is multiplied by the uncovered share of
the 45-number field, a declared fixed heuristic rather than an empirically fitted
probability. Unavailable stage evidence uses the existing coverage-novelty term
as an explicit fallback. No stage gate is lowered and no new family vote is added.
EP-R1 is unplayed and never adopted automatically; evidence admission for live
stage support remains unchanged. The display name Cross-group Support replaces
the misleading Independent Evidence label without rewriting the stored role ID.

EP-AUDIT-1 reconstructs both models and uniform controls for real targets with
only preceding history. The fixed seed bank is 0, 1, 17, 42; all seeds contribute,
with no winning-seed selection. Training requires at least 60 draws and the
whole requested fixed window. Local scope controls never change WFMQYH or infer
historical user presets. Each target retains actual roles, cutoff, all generated
rows, six-ticket main/supplementary matches, all-eight matches, supplementary-role
matches, actual six-ticket prizes, union size/hits, overlap and family removals.

The primary metric is six-ticket actual-main matches. Chronological 70/30 blocks
and a fixed conservative month-level screen distinguish retrospective exploration
from prospective evidence. A positive retrospective result still only permits
forward shadow monitoring; a negative result never tunes itself into a success.
The comparison runs in a cancellable worker; exporting retains complete evidence
and skips, and changed history or scope marks retained results stale.

## Neighbour and Terminal Scope Boundaries

The unrestricted immediate-previous-draw +/-1/+/-2 cloud is not interchangeable
with +/-1 only or a generator's eligibility-filtered targets. Ordinal recurrence
must be compared with the exact expectation from the cloud's size. Terminal-family
effects also need exposure-aware references: arithmetic creates directional family
relationships, endpoint clipping and overlapping targets. Drawn terminal shape is
an outcome, not a pre-draw feature.

An eight-number draw has 22,935 feasible exact terminal-count vectors but only 18
feasible repetition shapes. A future user-requested shape quota could use selected
WFMQYH shares, renormalised like odd/even quotas. It is not implemented here and
must not be smuggled into EP as an additional frequency-derived vote. Joint parity,
terminal and bucket quotas require feasibility checks rather than silent relaxation.
